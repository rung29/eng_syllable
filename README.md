# 英語冒險島 · English Quest

給國小生的繁體中文網頁遊戲。可以用滑鼠、觸控或鍵盤遊玩，每一題都能照自己的步調作答。

## 開始遊玩

- 直接用瀏覽器開啟 `index.html`。Windows 也可以雙擊 `start_game.bat`。
- 同一個 Wi-Fi 上的手機或平板可以透過電腦遊玩。在專案目錄執行 `python server.py`，然後在手機或平板開啟終端機顯示的區域網路網址。

## 四個關卡

| 關卡 | 練習內容 |
| --- | --- |
| 字母配對 | 辨認 26 個英文字母的大小寫。 |
| 生活單字 | 用動物、食物和日用品練習英中對照。 |
| 基礎句型 | 練習 `am / is / are`、`a / an` 和短句理解。 |
| 音節道館 | 選一位夥伴，在字母之間選擇切點，依序練習複合字、雙寫子音、子音分組、第一段是開音節的單字與混合題。 |

字母、單字與句型每回合各抽 6 題。答錯會顯示提示並可重試，結算時可以複習錯題。完成回合可得 1 顆星，首次答對 4 至 5 題得 2 顆星，6 題全對得 3 顆星。

在音節道館可切換提示、重聽整個單字，以及在答對後重聽個別音節。選擇「下一題」再繼續。發音使用裝置提供的合成語音，音節單獨朗讀的效果會因語音而異。

練習最佳星數與音節道館排行榜都記在目前的瀏覽器。音節道館可用預設暱稱進入。

## 題庫

- `js/practice-questions.js` 包含字母、生活單字和基礎句型。
- `js/words.js` 包含音節題。每題附有字義、拆法、提示和發音資料。`splitIndex` 代表切點左邊的字母數，例如 `pancake` 的切點是 `3`（`pan | cake`）。
