# 英語冒險島 · English Quest

給國小生的繁體中文網頁遊戲。可以用滑鼠、觸控或鍵盤遊玩，每一題都能照自己的步調作答。

## 開始遊玩

- 直接用瀏覽器開啟 `index.html`。Windows 也可以雙擊 `start_game.bat`。
- 同一個 Wi-Fi 上的手機或平板可以透過電腦遊玩。在專案目錄執行 `python server.py`，然後在手機或平板開啟終端機顯示的區域網路網址。

## 四個關卡

| 關卡 | 練習內容 |
| --- | --- |
| 字母配對 | 辨認 26 個英文字母的大小寫。 |
| 生活單字 | 用動物、食物和日用品練習英中對照。 |
| 基礎句型 | 練習 `am / is / are`、`a / an` 和短句理解。 |
| 音節道館 | 選一位夥伴，在字母之間選擇切點，依序練習複合字、雙寫子音、子音分組、第一段是開音節的單字與混合題。 |

字母、單字與句型每回合各抽 6 題。答錯會顯示提示並可重試，結算時可以複習錯題。完成回合可得 1 顆星，首次答對 4 至 5 題得 2 顆星，6 題全對得 3 顆星。

音節道館的腰帶關卡每回合會重新抽題，並優先選近期較少出現的單字。可以切換提示、重聽整個單字，部分腰帶單字在答對後也能重聽個別音節。發音使用裝置提供的合成語音。

### 音節出題設定

在首頁的音節道館區或遊戲內按「音節出題設定」。可選動物、食物、學校、日常生活、自然或運動與活動，也可選 1–4 音節、混合音節、難度和每回合題數。練習時先標記所有切點，再檢查答案；單音節題直接選「整個字是 1 音節」。如果條件較窄，會以符合的單字數出題。

- **內建題庫**可直接抽題。題組順序會變動，每回合不會出現相同單字，重新抽題時會優先換用近期未出現的單字。
- **Gemini 題庫**由家長或老師在設定頁輸入自己的 Gemini API 金鑰，按「儲存於此瀏覽器」，再按「產生 Gemini 題目」。先看字義和拆法，確認後可保存勾選的題目。之後可以從已審閱題庫抽題，也能重新產生。
- 各瀏覽器分開保留金鑰、設定和審閱過的題目。產題時瀏覽器直接向 Google 請求，不會將金鑰寫進遊戲原始碼或傳給網站伺服器。設定頁可清除金鑰，共用裝置適合用完即清除。其他玩家可直接用內建題庫。

自選練習會顯示一次答對的題數。腰帶晉級和道館排行榜依腰帶闖關成績計算。

練習最佳星數與音節道館排行榜都記在目前的瀏覽器。音節道館可用預設暱稱進入。

## 題庫

- `js/practice-questions.js` 包含字母、生活單字和基礎句型。
- `js/words.js` 包含原有腰帶音節題。`splitIndex` 代表切點左邊的字母數，例如 `pancake` 的切點是 `3`（`pan | cake`）。
- `js/dojo-bank.js` 包含按主題與難度整理的自選題庫，行內以點標出切點，例如 `ba.na.na|香蕉`。
